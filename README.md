# Tachkila v2

Application web de gestion d'effectif, de composition tactique et de suivi des matchs pour le club Atlas FC.

## Pages

- **Effectif** (`index.html`) : ajouter, modifier et supprimer des joueurs
- **Composition** (`composition.html`) : placer les joueurs sur le terrain en 4-4-2
- **Matchs** (`matchs.html`) : suivre les matchs et saisir les scores

## Technologies

- HTML5
- Tailwind CSS
- JavaScript ES6+ (modules)
- CSS Grid
- localStorage
